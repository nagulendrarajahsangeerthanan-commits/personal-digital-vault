# 🛡️ Personal Digital Vault & Credential Manager

A secure, cloud-enabled digital vault and credential management system designed to protect sensitive credentials, files, and identity records. Built with modern web technologies, strict Role-Based Access Control (RBAC), and enterprise-grade file handling.

---

## 🌟 Key Features

- **🔐 End-to-End Credential Management:** Securely add, view, copy, rename, and manage personal and team credentials.
- **📁 Encrypted File Vault:** Direct PC file upload, secure cloud persistence, and one-click downloading for essential documents.
- **👥 Role-Based Access Control (RBAC):** Admin and standard user roles with differentiated privileges and audit logging.
- **💳 Freemium Tier & Upgrade Quota:** Usage tracker and integrated subscription plans for premium tier storage.
- **🎨 Responsive Cyber-Vault UI:** High-contrast, clean cybersecurity aesthetic with modular sidebar navigation.

---

## 🏗️ Architecture & Tech Stack

- **Frontend:** React.js, Vite, Pure CSS Styling
- **Authentication:** Clerk Auth / Custom RBAC Layer
- **Backend:** Node.js, Express.js
- **Database & Storage:** Supabase Cloud Storage & Database Services
